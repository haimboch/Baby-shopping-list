# Baby Smart List v0.53 — גרסת שימוש

גרסה 0.53 מחברת את זהות המוצר, צילום האריזה וההתראות למסלול אחד שעובד גם במכשיר נייד.

## מה מוכן

- לכל 431 פריטי הקטלוג הפעילים יש ברקוד תקין וייחודי.
- מוצר במעקב נחשב מוכן רק אחרי בחירת אריזה מדויקת; הברקוד מוצג בכרטיס הראשי.
- תמונה מוצגת רק בהתאמה לברקוד. מקורות Super-Pharm ו־KSP שומרים מעכשיו גם את צילום האריזה הרשמי.
- כשאין צילום רשמי, בן משפחה יכול לצלם את האריזה. הקובץ נשמר ב־Supabase Storage פרטי ונגיש רק לחברי אותו בית.
- Push הופעל מחדש לחוסר, מלאי נמוך ומבצע למוצר המדויק. כל מכשיר עדיין חייב לתת הרשאת התראות פעם אחת מתוך מסך 🔔.
- לחיצה על Push פותחת את המוצר הרלוונטי, ולא מסך כללי.
- יצירת התראות המבצע אוחדה להרצה אחת אחרי כל עדכון מחירים.
- מנגנון dedupe מונע התראות זהות בחלונות זמן מוגדרים; 16 כרטיסי מבצע היסטוריים זהים הוסרו.
- נוספו אייקוני PWA להתקנה תקינה במסך הבית.

## בדיקות שבוצעו

- `python self_test.py`
- `python -m pytest -q` — 134 בדיקות עברו
- `node tests/v047_frontend_harness.mjs` — כל תרחישי המלאי, הסלים, המבצעים והחלופות עברו
- בדיקת transaction מול Supabase אישרה ששני אירועים זהים מייצרים התראה אחת בלבד לכל נמען
- Edge Function `notification-push-v032` פעילה בגרסה 5, ונתיב קבלת מפתח ה־Push תקין

## הפעלה ראשונה במכשיר

1. פותחים את האפליקציה דרך HTTPS. באייפון מוסיפים קודם למסך הבית.
2. נכנסים ל־🔔 התראות ולוחצים **הפעל Push במכשיר הזה**.
3. מאשרים את בקשת ההתראות של הדפדפן.
4. בכל מוצר שמסומן "חסרים אריזה וברקוד", בוחרים את האריזה המדויקת. אם אין צילום רשמי, מצלמים את האריזה מהכרטיס.

## מגבלת אמת

תמונה רשמית אינה מומצאת לפי שם: היא מוצגת רק כשמקור רשמי החזיר אותה עבור אותו ברקוד. בעת פרסום הגרסה קיימות 22 תמונות רשמיות מתוך 431 פריטי קטלוג פעילים; הכיסוי ימשיך לגדול בעדכונים האוטומטיים. מסלול הצילום הפרטי מאפשר להשלים מיד כל מוצר משפחתי שחסרה לו תמונה.
