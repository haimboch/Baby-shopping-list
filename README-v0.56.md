# Baby Smart List v0.56 — Pilot Ready

גרסה 0.56 מכינה את האפליקציה להפעלה אצל משפחות אמיתיות, בלי לשנות את מנגנון המחירים וה־Push שכבר עובד.

## מה נוסף

- מסך **מוכנות לפיילוט** שבודק בזמן אמת:
  - שני משתמשים במשפחה;
  - Push פעיל אצל כל המשתמשים;
  - לפחות שלושה מוצרים פעילים;
  - לפחות שלושה מוצרים עם ברקוד מדויק;
  - אזור קנייה ורדיוס;
  - התקנת האפליקציה במכשיר הנוכחי.
- כפתור התקנת PWA והוראות מותאמות לאייפון ולאנדרואיד.
- מסך עזרה ומשוב לדיווח על תקלה, התראה, נתון שגוי או הצעה.
- מדדי שימוש בסיסיים ומוגבלים לפיילוט, עם אפשרות לכבות איסוף עתידי בכל מכשיר.
- מסך פרטיות המסביר אילו נתונים נשמרים.
- בקשת מחיקת חשבון או משפחה וביטול בקשה שנמצאת בהמתנה. מחיקת משפחה זמינה רק למנהל/ת המשפחה.
- מטמון Service Worker חדש כדי שמכשירים יקבלו את גרסה 0.56 ולא יישארו על גרסה ישנה.

## מה נשמר ללא שינוי

- התראת Push אמיתית ממשיכה להישלח גם כשהאפליקציה סגורה.
- לחיצה על התראת מוצר פותחת את השוואת המחירים של אותו מוצר באזור המשפחה.
- ברקוד ותמונה משויכים לאריזה המדויקת בלבד.
- בתמ״ל לא מציעים החלפה למוצר אחר.
- איסוף תמונות האריזה המאומתות ממשיך אוטומטית כל שש שעות באמצעות GitHub Actions.
- כאשר אין תמונה מאומתת, אפשר לצלם את האריזה מתוך כרטיס המוצר; הצילום נשמר באופן פרטי למשפחה.

## מצב הנתונים בזמן הכנת הגרסה

- 2 משתמשים במשפחה ו־2 משתמשים מחוברים ל־Push.
- 9 מוצרים פעילים.
- 8 מוצרים עם ברקוד מדויק.
- 3 מוצרים עם תמונת אריזה זמינה.
- מיקום ורדיוס קנייה מוגדרים.

לכן תשתית הפיילוט המשפחתית מוכנה, אך עדיין צריך להשלים תמונות לחמש אריזות שכבר זוהו. ה־Action האוטומטי ימשיך לחפש תמונות, ואפשר להשלים מיד באמצעות צילום האריזה במכשיר.

## מסד הנתונים

המיגרציה `20260907235608_v056_pilot_ready.sql` כבר הוחלה על פרויקט Supabase הפעיל. היא מוסיפה:

- `pilot_events` — אירועי שימוש מוגבלים וללא טקסט חופשי;
- `pilot_feedback_reports` — פניות ומשוב;
- `data_deletion_requests` — בקשות מחיקה הפיכות כל עוד הן בהמתנה;
- `get_pilot_readiness_v056` — בדיקת מוכנות מאובטחת למשפחה.

לכל הטבלאות החדשות יש RLS והרשאות API מצומצמות. הפונקציה בודקת שהמשתמש חבר במשפחה לפני החזרת נתונים מצטברים.
